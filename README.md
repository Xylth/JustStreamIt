 
# Projet JustStreamIt

Ce projet est une interface graphique responsive qui utilise l'api OCMovies


## Pré-requis

Python 3.13.3

## Installation

Récupérer le repository via la commande :
```
git clone https://github.com/Xylth/JustStreamIt.git
```
Se rendre à la racine du repository via la commande :
```
cd JustStreamIt
```
Installer et lancer l'api via le makefile:
```
make
```

## Utilisation

Pour utliser le projet, s'assurer de lancer l'api via le makefile à la racine du projet et ouvrir le fichier index.html
